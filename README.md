Project 1 for IronHack's Web Development Bootcamp

The main goal was to create a simple game, using HTML, CSS, Javascript, DOM manipulation and Classes.
The game has a startScreen, a gameScreen, winnerScreen/loseScreen. The last screen has a button that allows the user to go back to the gameScreen and give it another shot.

My game is set in a bakery, where the player has to catch objects falling from the sky. It has an old game type of feel because I wanted to create a game that I would have played when I was young.
Some of the objects are worth cartching while others aren't.
- Good objects: mil folhas, bola de berlim, salame de chocolate, travesseiro de Sintra.
- Each one is worth 1 point, (minus the pastel de nata, worth 5 points)

But, there are also bad objects: 
- Knife: if you touch it, it's instant game over.
- Moldy cake: catch 3 and it's game over
- Burnt Croissant: catch 5 and it's game over

If you lose the game, the loseScreen will be displayed but with an image reflecting the reason why the player lost.

Used Google to find images;
Used https://makebead.com/pixel-art-converter/ to pixelate images
Used Canva (overlay images feature) to create the startScreen and the gameOver scenarios-
